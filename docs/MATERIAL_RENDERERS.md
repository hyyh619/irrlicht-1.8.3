# Material Renderers Module

## 1. Functionality

The Material Renderers module is responsible for translating high-level material definitions into actual GPU rendering operations. This module consists of two subsystems:

* **Shader-Based Material Rendering**: Implements `IMaterialRenderer` for programmable pipeline (GLSL, HLSL, Cg).
* **Software Triangle Rendering**: Low-level pixel operations (`ITriangleRenderer`) used by the software driver and for reference.

## 2. Primary Interfaces

### 2.1 `IMaterialRenderer` (`irr::video`)
Interface for all material renderers (used by video drivers).

| Method | Description |
| :--- | :--- |
| `OnSetMaterial(material)` | Called when material changes; sets render states, shaders. |
| `OnRender(services)` | Called before each draw call; sets dynamic shader constants. |
| `OnUnsetMaterial()` | Called when switching away from this material. |
| `isTransparent()` | Returns true if alpha-blended (for sorting). |
| `getRenderCapability()` | Returns fallback status (0=ok, >0=fallback used). |

### 2.2 `ITriangleRenderer` (`irr::video`)
Low-level software triangle rasterizer.

| Method | Description |
| :--- | :--- |
| `setRenderTarget(surface, viewport)` | Sets the render buffer. |
| `drawIndexedTriangleList(...)` | Rasterize indexed triangles. |
| `setTexture(texture)` | Binds the texture. |
| `setBackfaceCulling(enabled)` | Controls face culling. |

## 3. Core Data Structures

* **`SMaterial`**: Material definition (shading, lighting, textures, blending).
* **`E_MATERIAL_TYPE`**: Material types (`EMT_SOLID`, `EMT_TRANSPARENT`, `EMT_ONETEXTURE_BLEND`, etc.).
* **`S2DVertex`**: 2D screen-space vertex (for software rendering).
* **`E_VERTEX_TYPE`**: Vertex formats (`EVT_STANDARD`, `EVT_2TCOORDS`, etc.).
* **`E_PIXEL_SHADER_TYPE`**: Shader models (`EPST_PS_1_1` through `EPST_PS_3_0`).
* **`E_VERTEX_SHADER_TYPE`**: Vertex shader models (`EVST_VS_1_1` through `EVST_VS_3_0`).

## 4. Software Renderers (CTR* Classes)

These classes implement the fixed-function software pipeline:

| Class | Description |
| :--- | :--- |
| `CTRFlat` | Flat shading (no interpolation). |
| `CTRGouraud` | Gouraud shading (vertex color interpolation). |
| `CTRTextureFlat` | Texture mapping, flat shading. |
| `CTRTextureGouraud` | Texture mapping, Gouraud shading. |
| `CTRNormalMap` | Normal mapping (parallax). |
| `CTRGouraudAlpha` | Alpha-blended Gouraud. |
| `CTRTextureGouraudAdd` | Additive blending. |

## 5. Inter-Module Communication

* **Video Driver**: Calls `IMaterialRenderer::OnSetMaterial()` before rendering each mesh.
* **Scene Graph**: Materials are stored in `IMesh` and passed to the driver via `setMaterial()`.
* **Software Driver**: Uses `ITriangleRenderer` for direct pixel manipulation.

## 6. Interaction with Video Drivers

The driver holds a pool of material renderers:
```
driver->MaterialRenderers[EMT_SOLID] = new CTRGouraud(); // for software
driver->MaterialRenderers[EMT_SOLID] = new COpenGLShaderMaterialRenderer(); // for GL
```

When rendering:
```
driver->setMaterial(someMesh->getMaterial());
// -> driver calls materialRenderer->OnSetMaterial()
// -> driver calls drawVertexPrimitiveList()
// -> inside draw, materialRenderer->OnRender()
```
