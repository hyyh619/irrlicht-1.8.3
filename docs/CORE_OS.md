# Core & OS Module

## 1. Functionality

The Core & OS module provides the fundamental operating system abstraction layer for the Irrlicht Engine. It handles platform-independent operations including:
* **File I/O**: Reading/writing files to disk, virtual file systems, and archive handling (zip, pak, tar).
* **Logging**: Centralized logging system for debugging and error reporting.
* **Timer**: Time measurement for delta time calculation, performance timing, and virtual game time.
* **Math Utilities**: Random number generation and byte-order swapping (endianness).
* **Printer**: Console output for debug messages.

## 2. Primary Interfaces

### 2.1 File System (`irr::io::CFileSystem`)
Implements `IFileSystem`. Manages files, directories, and archives.

| Method | Description |
| :--- | :--- |
| `createAndOpenFile(path)` | Opens a file for reading. |
| `createAndWriteFile(path)` | Opens/creates a file for writing. |
| `addFileArchive(path)` | Mounts an archive (zip, pak, etc.). |
| `createFileList()` | Lists files in the working directory. |
| `getAbsolutePath(path)` | Converts relative paths to absolute paths. |
| `createXMLReader(path)` | Creates an XML parser for reading config files. |

### 2.2 Logger (`irr::CLogger`)
Implements `ILogger`. Routes log messages to the console or debug output.

| Method | Description |
| :--- | :--- |
| `log(text, level)` | Logs a message with a specific severity level. |
| `setLogLevel(level)` | Filters messages below the set level. |

### 2.3 Timer (`irr::os::Timer`)
Provides game time and real-time clock functionality.

| Method | Description |
| :--- | :--- |
| `getTime()` | Returns the current virtual game time (in ms). |
| `getRealTime()` | Returns wall-clock time. |
| `setSpeed(factor)` | Sets the speed of the virtual timer (for slow-motion, etc.). |
| `tick()` | Updates the virtual timer based on elapsed real time. |

### 2.4 Randomizer (`irr::os::Randomizer`)
Seeded pseudo-random number generator.

| Method | Description |
| :--- | :--- |
| `rand()` | Returns an integer in `[0, RAND_MAX]`. |
| `frand()` | Returns a float in `[0.0, 1.0]`. |
| `reset(seed)` | Re-seeds the generator. |

### 2.5 File Handles
* **`CReadFile`** (`irr::io`): Wraps `FILE*` for binary reading.
* **`CWriteFile`** (`irr::io`): Wraps `FILE*` for binary writing.
* **`CMemoryFile`** (`irr::io`): Provides file-like access to a memory buffer.

## 3. Core Data Structures

* **`io::path`**: A `core::string<>` type used throughout the engine for OS-native paths.
* **`IFileArchive`**: Interface for archive formats (ZIP, PAK, etc.).
* **`IArchiveLoader`**: Plugin mechanism for new archive types.
* **`IFileList`**: Result of directory listing queries.
* **`ELOG_LEVEL`**: Enum: `ELL_NONE`, `ELL_ERROR`, `ELL_WARNING`, `ELL_INFORMATION`, `ELL_DEBUG`.

## 4. Inter-Module Communication

* **Video Driver**: Uses `os::Timer` for frame timing and `CFileSystem` for loading texture assets.
* **Scene Manager**: Uses `os::Timer` for animation delta time.
* **Resource Loading**: Uses `CFileSystem` and `CReadFile` to load mesh/texture data.
* **GUI**: Uses `CLogger` to report errors (e.g., missing fonts).
* **Device Abstraction**: Uses `os:: Printer` to output early boot logs before other systems are initialized.

## 5. Dependencies

* **Public API**: Types in `include/IRRGL/` and containers in `include/IRRCC/`.
* **3rd Party**: None (pure C/C++ standard library).
* **Platform**: Directly uses standard C `FILE*` I/O. Platform-specific init is in `CIrrDevice`.
