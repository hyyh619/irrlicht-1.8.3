# Collision & Physics Module

## 1. Functionality

The Collision & Physics module provides collision detection and ray-casting services for game logic:
* **Ray Casting**: Screen-to-world and world-to-screen coordinate conversion.
* **Triangle Picking**: Ray-triangle intersection tests.
* **Collision Response**: Ellipsoid-based character physics with gravity and sliding.
* **Spatial Partitioning**: Accelerating structures for collision queries.

## 2. Primary Interfaces

### 2.1 Scene Collision Manager: `CSceneCollisionManager` (`irr::scene`)
Manages all collision queries.

| Method | Description |
| :--- | :--- |
| `getSceneNodeFromScreenCoordinatesBB(pos)` | Picks node at screen coords (AABB). |
| `getSceneNodeFromRayBB(ray)` | Picks node with ray (AABB). |
| `getCollisionPoint(ray, selector)` | Ray-triangle intersection. |
| `getCollisionResultPosition(selector, ...)` | Movement with collision response. |
| `getRayFromScreenCoordinates(pos, camera)` | Converts 2D → 3D ray. |
| `getScreenCoordinatesFrom3DPosition(pos)` | Converts 3D → 2D screen. |

### 2.2 Triangle Selector: `ITriangleSelector` (`irr::scene`)
Interface for accessing triangles.

| Method | Description |
| :--- | :--- |
| `getTriangleCount()` | Returns triangle count. |
| `getTriangles(triangles, arraySize, outIndices)` | Fills an array with triangles. |

## 3. Core Data Structures

* **`core::line3d<f32>`**: A 3D ray (start, end).
* **`core::triangle3d<f32>`**: A triangle (3 vertices).
* **`core::aabbox3d<f32>`**: Axis-aligned bounding box (for fast culling).
* **`SCollisionData`**: Internal tracking for collision traversal.

## 4. Selector Implementations

| Class | Description |
| :--- | :--- |
| `CTriangleSelector` | Naive O(n) linear scan. |
| `COctreeTriangleSelector` | Octree-accelerated queries. |
| `CMetaTriangleSelector` | Merged multiple selectors. |
| `CTerrainTriangleSelector` | Heightmap terrain optimization. |
| `CTriangleBBSelector` | Bounding box culling + triangle exact. |

## 5. Inter-Module Communication

* **Scene Graph**: Uses collision nodes to detect input (picking).
* **Video Driver**: Used to convert 3D world positions to 2D screen coordinates (for GUI).
* **Animators**: `ISceneNodeAnimatorCollisionResponse` uses this for character movement.
