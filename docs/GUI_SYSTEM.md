# GUI System Module

## 1. Functionality

The GUI System module provides a 2D user interface framework for creating in-engine UIs (menus, HUDs, dialogs). It includes:
* **Windowing System**: Hierarchies of GUI elements with parent-child relationships.
* **Input Handling**: Mouse and keyboard events routed to focused elements.
* **Rendering**: 2D drawing via the video driver (text, images, primitives).
* **Skinning**: Customizable look-and-feel via `IGUISkin`.
* **Sprites**: Image-based icon sets for buttons and controls.

## 3. Core Data Structures

* **`IGUIElement`**: Base for all controls (buttons, sliders, windows).
* **`SEvent`**: Input event structure (mouse move, key press, etc.).
* **`EGUI_SKIN_TYPE`**: Skin templates (`EGST_WINDOWS_METALLIC`, `EGST_CLASSIC`, etc.).
* **`video::ITexture`**: Used for button icons and background images.

## 5. Inter-Module Communication

* **Video Driver**: GUI uses `driver->draw2DImage()` and `driver->draw2DRectangle()` to render.
* **Input**: Device layer posts events to the environment via `postEventFromUser()`.
* **Scene Graph**: GUI is rendered after the 3D scene (or on top).
* **Core & OS**: Uses `CLogger` for error messages.
