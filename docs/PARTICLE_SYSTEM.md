# Particle System Module

## 1. Functionality

The Particle System module provides visual effects (fire, smoke, rain, sparks) via GPU-accelerated billboards:
* **Emitters**: Spawning particles at defined rates and locations.
* **Affectors**: Modifying particles over time (gravity, fade, rotation).
* **Rendering**: Billboard sprites always face the camera.

## 2. Primary Interfaces

### 2.1 Particle System: `CParticleSystemSceneNode` (`irr::scene`)
Manages and renders particles.

| Method | Description |
| :--- | :--- |
| `setEmitter(emitter)` | Sets particle source. |
| `addAffector(affector)` | Adds a modifier (gravity, fade, etc.). |
| `getAffectors()` | Returns list of affectors. |
| `removeAllAffectors()` | Clears all modifiers. |
| `render()` | Draws all particles. |

### 2.2 Particle Emitter: `IParticleEmitter` (`irr::scene`)
Creates new particles.

| Method | Description |
| :--- | :--- |
| `emitParticles(now)` | Spawns particles for this frame. |
| `getMinParticlesPerSecond()` | Spawn rate (min). |
| `getMaxParticlesPerSecond()` | Spawn rate (max). |

### 2.3 Particle Affector: `IParticleAffector` (`irr::scene`)
Modifies particles over their lifetime.

| Method | Description |
| :--- | :--- |
| `affect(now, particles, count)` | Modifies particle array. |

## 3. Core Data Structures

* **`SParticle`**: Particle state (position, direction, color, size, age).
* **`core::dimension2df`**: Particle size.
* **`video::SColor`**: Particle color (with alpha).

## 4. Emitter Implementations

| Class | Description |
| :--- | :--- |
| `CParticleBoxEmitter` | Emits from a 3D box volume. |
| `CParticleSphereEmitter` | Emits from a sphere surface. |
| `CParticleCylinderEmitter` | Emits from a cylinder. |
| `CParticleRingEmitter` | Emits from a ring. |
| `CParticlePointEmitter` | Emits from a single point. |
| `CParticleMeshEmitter` | Emits from a mesh surface. |

## 5. Affector Implementations

| Class | Description |
| :--- | :--- |
| `CParticleGravityAffector` | Applies gravity (downward acceleration). |
| `CParticleFadeOutAffector` | Fades alpha over lifetime. |
| `CParticleRotationAffector` | Rotates particle direction. |
| `CParticleScaleAffector` | Scales size over time. |
| `CParticleAttractionAffector` | Pulls particles toward a point. |

## 6. Inter-Module Communication

* **Scene Graph**: `CParticleSystemSceneNode` is a scene node, rendered by the manager.
* **Video Driver**: Uses `driver->draw2DImage()` to draw billboard sprites.
* **Core & OS**: Uses `os::Timer` for particle age calculations.
