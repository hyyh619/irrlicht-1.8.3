# Rendering Drivers Module

## 1. Functionality

The Rendering Drivers module provides the hardware abstraction layer (HAL) for the Irrlicht Engine. It is responsible for:
* **Rendering**: Managing the graphics pipeline (render passes, state changes, draw calls).
* **Texture Management**: Loading, caching, and binding GPU textures.
* **Frame Management**: Beginning and presenting frames (`beginScene` / `endScene`).
* **Shader Support**: Compiling and applying vertex/pixel shaders (GLSL, HLSL, Cg).
* **Geometry**: Managing vertex buffers, index buffers, and mesh caching.
* **State Management**: Viewports, clip planes, fog, lighting, render targets.

This module implements the `IVideoDriver` interface and is extended by platform-specific implementations.

## 2. Primary Interfaces

### 2.1 Base Class: `CNullDriver` (`irr::video`)
Provides common functionality for all drivers (texture cache, image loaders, attribute handling).

| Method | Description |
| :--- | :--- |
| `getTexture(path)` | Loads and caches a texture by path. |
| `addTexture()` | Creates a new empty texture. |
| `setMaterial(material)` | Sets the current rendering material. |
| `setTransform(state, mat)` | Sets world/view/projection matrices. |
| `draw3DLine(start, end, color)` | Debug line drawing. |
| `setRenderTarget(texture)` | Switches to render-to-texture. |

### 2.2 OpenGL Driver: `COpenGLDriver` (`irr::video`)

| Method | Description |

| Method | Description |

## 3. Core Data Structures

* **`SMaterial`**: The central material structure (diffuse, ambient, specular, emissive colors, textures, shading mode).
* **`SHWBufferLink`**: Hardware buffer abstraction (Vertex Buffer Objects in OpenGL, Vertex/Index Buffers in D3D).
* **`SDepthSurface`**: D3D depth stencil surface.
* **`SLight`**: Dynamic light definition (type, position, attenuation, diffuse intensity).
* **`ITexture`**: Interface for all texture types.
* **`ECOLOR_FORMAT`**: Enum for pixel formats (ECF_A8R8G8B8, ECF_DXT1, etc.).
* **`E_RENDER_TARGET`**: Enum for render targets (ERT_FRAME_BUFFER, ERT_AUX_BUFFER0-3).

## 4. Inter-Module Communication

* **Scene Graph**: `CSceneManager` calls `driver->drawVertexPrimitiveList()` to render meshes.
* **GUI**: `CGUIEnvironment` uses the driver to draw 2D elements.
* **Particle System**: Uses the driver to render billboard particles.
* **Core & OS**: The driver uses `os::Timer` for frame timing (`getRealTime()`).

## 5. Derived Implementations

* **COpenGLDriver**: Linux, Windows, macOS, SDL.
* **CD3D9Driver**: Windows DirectX 9.
* **CD3D8Driver**: Older Direct3D 8 (rarely used).
* **CSoftwareDriver**: Software rendering (fallback, testing).
* **CNullDriver**: Null device (headless server).
