# Scene Graph Module

## 1. Functionality

The Scene Graph module is the heart of the Irrlicht Engine's 3D scene management. It is responsible for:
* **Scene Hierarchies**: Managing a tree of `ISceneNode` objects with parent-child relationships.
* **Rendering Pipeline**: Traversing the scene graph and issuing draw calls to the video driver.
* **Camera Management**: Handling view and projection matrices.
* **Geometry Creation**: Creating primitives (boxes, spheres, terrain).
* **Node Animators**: Applying time-based transformations to nodes.
* **Optimizations**: Octree spatial partitioning for culling.

## 2. Primary Interfaces

## 3. Core Data Structures

* **`ISceneNode`**: Base class for all nodes.
* **`IMesh`**: Static geometry.
* **`IAnimatedMesh`**: Time-varying geometry (MD2, MD3, etc.).
* **`IMeshSceneNode`**: Renders `IMesh`.
* **`IAnimatedMeshSceneNode`**: Renders `IAnimatedMesh`.
* **`E_SCENE_NODE_RENDER_PASS`**: Render pass enumeration:
  - `ESNRP_SKY_BOX`: Background sky.
  - `ESNRP_SOLID`: Opaque geometry.
  - `ESNRP_TRANSPARENT`: Alpha-blended.
  - `ESNRP_SHADOW`: Shadow volume.
* **`ISceneNodeAnimator`**: Base for time-based animation.

## 4. Inter-Module Communication

* **Video Driver**: `CSceneManager` calls `driver->drawVertexPrimitiveList()` for each visible mesh.
* **GUI**: GUI elements are drawn after the 3D scene (in `ESNRP_TRANSPARENT` pass or separately).
* **Collision**: Uses the scene graph to perform ray casts (`CSceneCollisionManager`).
* **Core & OS**: Uses `os::Timer` for animation delta time.
