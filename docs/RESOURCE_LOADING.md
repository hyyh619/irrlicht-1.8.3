# Resource Loading Module

## 1. Functionality

The Resource Loading module handles all file I/O for 3D assets, including:
* **Mesh Loading**: Importing mesh formats (OBJ, MD2, MD3, 3DS, BSP, COLLADA, etc.).
* **Image Loading**: Importing texture formats (PNG, JPG, TGA, BMP, DDS, etc.).
* **XML Parsing**: Reading engine config files and custom XML formats.
* **Archive Support**: Transparent loading from ZIP, PAK, TAR, and other archives.
* **Caching**: Managing in-memory caches for meshes and textures.

## 2. Primary Interfaces

### 2.1 Mesh Cache: `CMeshCache` (`irr::scene`)
In-memory cache for loaded meshes.

| Method | Description |
| :--- | :--- |
| `addMesh(name, mesh)` | Registers a mesh in the cache. |
| `removeMesh(mesh)` | Removes from cache (frees memory). |
| `getMeshCount()` | Returns cached mesh count. |
| `getMeshByIndex(idx)` | Gets mesh by index. |
| `getMeshByName(name)` | Gets mesh by filename. |
| `getMeshName(idx)` | Returns the name of a cached mesh. |
| `renameMesh(idx, newName)` | Changes the mesh's name. |

### 2.2 Mesh Loader: `IMeshLoader` (`irr::scene`)
Base interface for mesh format loaders.

| Method | Description |
| :--- | :--- |
| `isALoadableFileExtension(ext)` | Checks if format is supported. |
| `createMesh(file)` | Creates `IAnimatedMesh` from file. |

### 2.3 Image Loader: `IImageLoader` (`irr::video`)
Base interface for texture format loaders.

| Method | Description |
| :--- | :--- |
| `isALoadableFileExtension(ext)` | Checks if format is supported. |
| `loadImage(file)` | Returns `IImage` from file. |

### 2.4 XML Reader: `IXMLReader` (`irr::io`)
Pull-style XML parser.

| Method | Description |
| :--- | :--- |
| `read()` | Moves to next node. |
| `getNodeType()` | Returns current node type. |
| `getAttributeValue(name)` | Gets attribute by name. |
| `getAttributeValueAsInt(name)` | Gets int attribute. |
| `getAttributeValueAsFloat(name)` | Gets float attribute. |
| `getReaderName()` | Returns current element name. |

### 2.5 Archive Readers
| Class | Description |
| :--- | :--- |

## 3. Core Data Structures

* **`IAnimatedMesh`**: Interface for animated mesh data (MD2, MD3 frames).
* **`IMesh`**: Static mesh geometry.
* **`IMeshBuffer`**: Subset of mesh with one material.
* **`SVertexIndex`**: Index buffer type (16-bit or 32-bit).
* **`SMesh`**: Implementation container.
* **`SNamedPath`**: Filename with search path priority.

## 4. Supported Formats

### Mesh Formats
* `.obj` - Wavefront OBJ.
* `.md2` - Quake 2.
* `.md3` - Quake 3.
* `.3ds` - 3D Studio.
* `.bsp` - Quake 3 BSP.
* `.dae` - COLLADA.
* `.irr` - Irrlicht native XML.
* `.ply` - Stanford PLY.

### Image Formats
* `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tga`, `.dds`, `.pcx`, `.ppm`.

## 5. Inter-Module Communication

* **Scene Manager**: Uses `IMeshLoader` via `getMesh()` to load meshes.
* **Video Driver**: Uses `IImageLoader` to load textures.
* **File System**: Provides `IReadFile` to loaders; mounts archives automatically.
* **Core & OS**: Uses `CFileSystem` for path resolution.
